# Code of conduct

This project welcomes contributors of all backgrounds and experience levels. Everyone participating in issues, pull requests and other project spaces is expected to follow these rules.

## Expected behavior

- Be respectful, patient and constructive.
- Discuss ideas and technical choices without attacking people.
- Accept good-faith feedback and correct mistakes.
- Respect other people's privacy and boundaries.

## Unacceptable behavior

Harassment, discriminatory language, threats, sexualized attention, personal attacks, sustained disruption and publication of private information without consent are not acceptable.

## Reporting and enforcement

Use GitHub's **Report content** option to report abusive content or conduct that violates [GitHub's Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines). Do not repeat private or harmful material in a public report.

For an ordinary repository moderation request, open an issue using the bug-report form and link to the relevant public interaction with minimal context. If reporting publicly would expose sensitive information or increase risk, use GitHub's reporting channel instead.

The maintainer may edit or remove inappropriate content, warn participants, limit interactions or block further participation. Responses should be proportionate to the behavior and its impact. These rules also apply to the maintainer. GitHub's policies and reporting mechanisms remain available independently of repository moderation.

Security vulnerabilities should be reported using [SECURITY.md](SECURITY.md), not as conduct reports.
